SAÉ 14 — Se présenter sur Internet

Contexte & Objectifs

Durée : 4 semaines | Travail individuel : Projet personnel

J'ai créé un site web personnel en respectant un cahier des charges spécifique. L'objectif était de maîtriser les technologies web fondamentales (HTML, CSS, JavaScript), d'apprendre à utiliser un IDE professionnel (VS Code) et de découvrir les outils collaboratifs (Git, GitHub). Ce projet simule la création d'une présence numérique, compétence clé pour un professionnel du numérique.

Activités Conduites

  • Conception et structure : Définition de l'architecture informationnelle et de la navigation du site
  • Développement frontend : Création en HTML et CSS avec application des principes de responsive design
  • Interactivité : Ajout de fonctionnalités JavaScript pour l'expérience utilisateur
  • Versioning : Gestion du projet avec Git, commits réguliers et synchronisation GitHub
  • Déploiement : Publication du site via GitHub Pages pour accès en ligne

Compétences Mobilisées

  • Utilisation d'un système informatique et ses outils (IDE, navigateurs, systèmes de versioning)
  • Connaissance de l'architecture et des technologies web (HTML, CSS, JavaScript)
  • Design responsive et accessibilité web
  • Collaboration et versioning avec Git/GitHub

Tâches Réalisées

  • J’ai créé un site personnel présentant mes hobbies, notamment le football.
  • J’ai développé le site en HTML et CSS.
  • ’ai créé un design responsive adapté aux différents écrans.
  • J’ai respecté le cahier des charges demandé pour le projet.
  • J’ai déployé le site sur GitHub.

Preuve

Voir le site publié : https://shooter224.github.io/projet_SAE/

Acquis de Compétences (AC)

  • AC13.01 – Utiliser un système informatique et ses outils
  • AC13.04 – Connaître l'architecture et les technologies d'un site Web
  • AC13.06 – S'intégrer dans un environnement propice au développement et au travail collaboratif

Autoévaluation

Points forts : J'ai maîtrisé les fondamentaux HTML/CSS et réussi à créer un design responsive fonctionnel sur tous les appareils. La publication sur GitHub Pages a validé ma compréhension de l'écosystème web et du déploiement en ligne.

Apprentissages clés : Cette SAÉ m'a ouvert les portes du développement web. J'ai compris l'importance de la structure et de la maintenabilité du code, ainsi que le rôle critique de la responsivité dans l'expérience utilisateur moderne.

Difficultés rencontrées : CSS et certaines fonctionnalités JavaScript ont été complexes au départ. J'ai sollicité l'aide d'IA et de Copilot pour mieux comprendre les concepts et corriger les erreurs logiques.

Améliorations possibles : Je pourrais explorer des frameworks modernes (React, Vue.js) pour améliorer la modularité du code. L'ajout d'un système de gestion de contenu ou d'une base de données dynamique ouvrirait des possibilités plus avancées.

Compétence renforcée : AC13.04 – Connaître l'architecture et les technologies d'un site Web.
