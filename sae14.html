SAÉ 14 — Se présenter sur Internet

Description

Réaliser un site web personnel en HTML et CSS en respectant un cahier des charges, tout en appliquant les bases du développement web. Le projet vise aussi à découvrir les standards du Web, utiliser un IDE comme Visual Studio Code et apprendre à versionner son travail avec Git et GitHub.

Apprentissages Critiques

  • Utiliser un système informatique
  • Connaître les technologies web
  • Travailler dans un environnement collaboratif

Tâches réalisées

  • J’ai créé un site personnel présentant mes hobbies, notamment le football.
  • J’ai développé le site en HTML et CSS.
  • ’ai créé un design responsive adapté aux différents écrans.
  • J’ai respecté le cahier des charges demandé pour le projet.
  • J’ai déployé le site sur GitHub.

Preuve

Voir le site publié : https://shooter224.github.io/projet_SAE/

Autoévaluation

J’ai appris à développer un site web en utilisant HTML, CSS et un peu de JavaScript. J’ai aussi travaillé sur le design responsive pour adapter le site aux différents écrans. J’ai rencontré quelques difficultés en CSS et pour certaines fonctionnalités, donc je me suis aidé de l’IA et de Copilot pour mieux comprendre et corriger certaines parties du code. Aujourd’hui, je suis plus à l’aise dans la création et la mise en ligne d’un site web, mais je dois encore progresser en JavaScript et en mise en page avancée.
